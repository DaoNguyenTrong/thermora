Cài Claude Code

  1. Nhờ người hỗ trợ bạn cài Claude Code trên máy này.

  2. Gửi người hỗ trợ bạn dòng dưới đây, hoặc mở trang hướng dẫn của Claude Code.

    npm install -g @anthropic-ai/claude-code
    Mở trang hướng dẫn

  3. Khi cài xong, chọn Kiểm tra lại.

Cài Codex

  1. Nhờ người hỗ trợ bạn cài Codex trên máy này.

  2. Gửi người hỗ trợ bạn dòng dưới đây, hoặc mở trang hướng dẫn của Codex.

    npm install -g @openai/codex
    Mở trang hướng dẫn

  3. Khi cài xong, chọn Kiểm tra lại.
