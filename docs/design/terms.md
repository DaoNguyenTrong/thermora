One wording per term (PRD-00 FR-10). Product names stay as Claude Code, Codex, Claude, ChatGPT and Thermora.

| Term | Vietnamese on screen |
|---|---|
| Display name | Tên hiển thị |
| Ready | Sẵn sàng |
| Not installed | Chưa có trên máy |
| Installed but not signed in | Đã có, chưa đăng nhập |
| Version not supported | Bản không dùng được |
| Cannot be checked | Chưa kiểm tra được |
| Service in use | Đang dùng |
| No choice yet | Chưa chọn |
| No service ready (title-bar summary) | Chưa sẵn sàng |
| Setup help | Hướng dẫn chuẩn bị |
| Supporter | Người hỗ trợ bạn |
| Check again | Kiểm tra lại |

| Working indicator | Đang kiểm tra |
| Took too long | Quá lâu |
| Reminder close | Đã hiểu |
| Placeholder action | Bắt đầu việc |

## Technical terms kept off ordinary messages

PRD01-BR-07 and D11. These words do not appear on a screen the person reads. They may appear only inside text the person chooses to copy for the supporter, and only when a version or a state needs them. The copy text in REL-1 uses none of them.

terminal, token, credential, API, CLI, stack trace, log, env, secret, endpoint, JSON, prompt, model, path, stdout, stderr, password

The screens also avoid mật khẩu. Sign-in is described as đăng nhập trên trang của Claude Code or Codex.
